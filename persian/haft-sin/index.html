The Haft-sin table

Haft-sin means "seven S". Persian families set a table before Nowruz with seven items whose names begin with the letter S (س). The symbolism listed is the common one; families explain the items differently, and no list is official. Many tables also hold a mirror, candles, decorated eggs, a bowl with goldfish, hyacinths, coins, a book of poems (often Hafez) or the Quran, and sweets.

Reading the list

Each item is chosen for its name as much as for its meaning, because the word has to start with the letter sin. Where an item is hard to find, many families substitute: for example, sprouted lentils or wheat for the sabzeh in a dish, and some use other items whose names begin with S. The table is meant to be shared: guests are shown it and given sweets, and it is left up until the thirteenth day.

When it is set

The table is set up in the days before Nowruz and stays until the thirteenth day. Families gather around it at the exact moment of the equinox. For the moment in 2027, see Nowruz 2027. The sabzeh is thrown into running water on the thirteenth day, Sizdah Bedar.
